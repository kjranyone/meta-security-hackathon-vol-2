Geopolitics Terrarium RL政策リプレイギャラリー

以下の全リプレイは、全国家を強化学習ポリシー(汎用DeepPolicyNet 約50MB・教師LLMから蒸留)で 運用して生成したものです。ルールベースのHAND-coded政策ではありません — 各国の予算配分・軍事姿勢・ 配給・外交は毎tickニューラルネットの推論で決定されています。16カ国版と176カ国の全国家版を 同一シナリオ・同一重みで並べてあります。 地図は基本静かで、事件が起きた瞬間だけ、その関係が発光する弧・リングとして浮かび上がり、約4秒で消えます。

現段階の精度は低い(教師一致率0.91・macro-F1 0.73、模倣と生存は別目的であることを実測)。 しかしこの訓練・配備パイプラインはAIが自律的に構築したものであり、計算資源と観測変数の定義を 増やすことで深いインサイトに到達できるか、という問いへの足場です。

本シミュレーションは現実世界の予測装置ではありません。事案 → 機序 → 数値の経路を 明示的に観察するための探索用具です(憲章と研究ログに主張の範囲を定義しています)。 国防政策の意思決定に用いることはできません。

エネルギー・シーレーン

ホルムズ海峡封鎖

エネルギー航路の途絶が価格と備蓄競争を伝播。RL世界では封鎖下で戦争1件が 発生(ルールベース政策では0件)。同じ介入でも政策の選択が分岐を作ります。t=6 の封鎖から。

 反実仮想(IF史)

IF: ホルムズを1tick早く封鎖したら

同じ世界・同じRL政策で介入だけt=6→t=5に前倒し。エネルギー価格は 2.93→2.61に収まり、戦争は発生しなかった — 介入時点1tickの差が帰結を分けました。

 金融・経済

世界金融危機

信用収縮が貿易効率を叩き、資源輸入国から順に不足イベントが連鎖。平均債務は 116%と、ルールベース政策(96%)より深刻化 — 学習ポリシーの運営が別の危険を作っています。

 半導体・台湾有事

台湾海峡の航路遮断

半導体シーレンの途絶がチップ価格を急騰させ、軍事・生産の両面に伝播します。

 日本の安全保障

日本の周辺情勢(米ハブ同盟網)

日本を米国ハブの同盟網(日米・米韓・米豪・米台)に置いた設定で台湾有事を扱う、 憲章の「現在の日本における安全保障リスク」の典型シナリオ。

 偽情報・ギャップチャネル

対日偽情報キャンペーン

平時の偽情報が慢性疑心を積み上げ、不足イベントを誘発する様子。慢性的な圧力が 一発の事件と別の経路で効く「ギャップチャネル」のデモです。

ブラウザ実行・ライブ

神モード・ブラウザ実行

サーバ不要。このページ内で本物のPythonエンジンと学習モデル1本(約50MB)が WASM(Pyodide)上で実行されます — 力学の移植ではなく同一コードなので、 ネイティブ実行と同seedで400tick・bit一致を検証済み。 シード/世界の差し替え、海峡封鎖・災害などの神介入もすべてブラウザ内で完結。

神モード(god.html)は介入WebSocketを持つPythonバックエンドが必要です (リポジトリをクローンして uv run python -m terrarium.server)。 学習・評価の主張の範囲は README ・ CHARTER ・ 研究ログ を参照してください。
