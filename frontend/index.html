Geopolitics Terrarium リプレイギャラリー

決定論的な地政学シミュレーションエンジンのリプレイビューア。地図は基本静かで、 事件が起きた瞬間だけ、その関係が発光する弧・リングとして浮かび上がり、約4秒で消えます。 タイムラインをスクラブすると、どの事案がどの経路(航路・海峡・同盟)に波及したかを追えます。

本シミュレーションは現実世界の予測装置ではありません。事案 → 機序 → 数値の経路を 明示的に観察するための探索用具です(憲章と研究ログに主張の範囲を定義しています)。 国防政策の意思決定に用いることはできません。

エネルギー・シーレーン

ホルムズ海峡封鎖

中東からのエネルギー航路が断たれ、価格急騰が世界に波及。t=6 から封鎖の瞬間を見られます。

 金融・経済

世界金融危機

信用収縮が貿易効率を叩き、資源輸入国から順に不足イベントが連鎖します。

 半導体・台湾有事

台湾海峡の航路遮断

半導体シーレンの途絶がチップ価格を急騰させ、軍事・生産の両面に伝播します。

 日本の安全保障

日本の周辺情勢(米ハブ同盟網)

日本を米国ハブの同盟網(日米・米韓・米豪・米台)に置いた設定で台湾有事を扱う、 憲章の「現在の日本における安全保障リスク」の典型シナリオ。

 偽情報・ギャップチャネル

対日偽情報キャンペーン

平時の偽情報が慢性疑心を積み上げ、不足イベントを誘発する様子。慢性的な圧力が 一発の事件と別の経路で効く「ギャップチャネル」のデモです。

 複合危機

三重危機

エネルギー・金融・食料のショックが同時にヒットする複合シナリオ。単一危機と 伝播の重なり方が変わります。

 反実仮想(IF史)

IF: ホルムズを5tick早く封鎖したら

同じ世界を別の介入時点で再実行した分岐リプレイ。決定論エンジンなので 違いは介入だけに由来します。

神モード(god.html)は介入WebSocketを持つPythonバックエンドが必要です (リポジトリをクローンして uv run python -m terrarium.server)。 学習・評価の主張の範囲は README ・ CHARTER ・ 研究ログ を参照してください。
