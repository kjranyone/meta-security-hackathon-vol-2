# Geopolitics Terrarium
**〜神の地政学とバタフライ・エフェクト〜**

第2回 AIエージェント社会シミュレーション・ハッカソン「メタ安全保障」（Singulab × AUTOMATA）応募作品。

**実世界地図上**の国家AIたちに対し、プレイヤーが「神」として海峡封鎖・偽情報投下・資源消滅などの介入を行い、**サプライチェーンの連鎖反応が世界をどう変えるか**を観測する非対称安全保障サンドボックスです。

## テーゼ

**全国家安全保障シミュレーター**。Natural Earthの全特徴をAI国家化し、
相互防衛・安全保障ジレンマ・核抑止・情報の霧を含む力学の下で、
危機の安定性をAI意思決定層と抑止構成の交換によって測定する。
パラメータが足りなければ足す — それがこのシミュレーターの開発原理である。

### Frontier力学（v3追加）

| 力学 | 実装 |
|---|---|
| **相互防衛** | 同盟国が開戦時に信頼に応じて参戦（`alliance_activation`イベント、開戦をparentに持つ因果追跡、連鎖深さ1） |
| **安全保障ジレンマ** | 信頼<15の敵対大国の軍事優位(>1.2×)が毎月好戦性+0.004・疑心+0.003を駆動 |
| **情報の霧** | 神スライダー `fog_of_war` 0-50%: 各国の信頼推定を平均(20)へ退行させ、誤認の源となる（エージェントは誤った情報で意思決定する） |

### 実時間校正（v4: 介入は即時に効かない）

神モードの時計は**1tick=1時間**。全動力学は**実時間（時間）で定義された時定数**
（`world/clock.py`）で走り、「何かをしたら数値が即座に変わる」ことは起きない:

| プロセス | 時定数/遅延 |
|---|---|
| 市場価格の発見 | τ≈36時間。封鎖ニュースは**期待ショック**として数時間で載る（在庫が尽きるより先に） |
| 航路封鎖の実効化 | τ≈10日 — 航行中の船はまだ到着する。再開後の回復はτ≈4日 |
| 戦争の動員 | 4〜30日（最頻10日）。緊張が臨界を超えても即時開戦せず、`mobilization`を経由。動員中に緊張が引けば`stand_down` |
| 同盟国の参戦協議 | 1日〜1週間の照会の後、信頼次第で履行 |
| インフレ期待 | τ≈6ヶ月。輸入価格のパススルーはCPI上限35%で正規化（5商品依存の単純和は二重計上） |
| 失業（オークン則） | τ≈4ヶ月 |
| GDP成長・人口 | 年率で複利（+2%/年が基調。月次複利の旧版は世界を急成長させていた） |
| 政府の意思決定 | 週次（168時間）。政府は毎時間閣議を開かない — 決定は次の決定点までstanding policyとして継続適用 |
| 財政・デフォルト | 四半期スケールのフローと月次ハザード |

ホルムズを封鎖すると（実測）: **1〜3日で期待による価格急騰 → 2〜4週間で実物の輸送力低下
（価格×2台へ）→ 備蓄揚耗の2〜3ヶ月後に不足とデフォルト → その先に動員と戦争**。
逆に3日間の観測では価格以外は何も壊れない — この約束を `tests/test_clock.py` が検証する。

### 安全保障パラメータ拡張（v5: 政府の異質性と古典的機構）

**思想・ドクトリン向量**（NationSpec、国ごとに異なる政策文化。中立的な分析用の様式化で、
特定国の実政策への言明ではない）:

| パラメータ | 効果 |
|---|---|
| `doctrine_risk` 危機許容度 | 緊張の立ち上がりを抑える（挑発に耐える政府） |
| `doctrine_militarism` 軍事偏重 | **リチャードソン軍拡方程数**の反応係数・平時の軍事予算・RL報酬の軍備効用。earth_allでは実軍事費比率から導出 |
| `doctrine_revisionism` 修正主義 | 緊張を煽る。heuristicでは高修正主義が脅迫外交を選ぶ |
| `doctrine_vengeance` 報復性 | 戦争の降伏閾値（疲弊への耐性）を伸ばす — 執拗に戦い続ける政府 |
| `doctrine_treaty_fidelity` 同盟遵守度 | 相互防衛条約の履行確率 |
| `nuclear_posture` 核態勢 | **counterforce / MAD / NFU** — 攻撃側の態勢が抑止係数を変える（counterforce ×0.75、NFU ×1.25） |

古典的な安全保障機構（`tests/test_doctrine.py` が検証）:

- **交渉による終戦**（Fearon型）: 力の不均衡と疲弊が深いほど講和が成立する —
  消耗衰亡（`war_end`）とは別の終わり方（`peace_settlement`）
- **軍備管理条約**: 核保有国同士の消耗戦は合意で凍結されうる（`arms_control`、軍縮+信頼回復）
- **内戦・反乱**: 統治崩壊領域（安定<15）で不平等・失業が不和を増幅しハザード化（`insurgency`）
- **核拡散連鎖**: 敵性核保有国の出現が対抗核追求を誘発（heuristicのdoctrine連鎖。
  思想・核保有は観測可能なのでLLM/RLも反応できる）
- **リチャードソン軍拡**: 敵性大国の軍備増加分に軍事偏重が比例反応する（行動-反応）

思想は全層から見える: RL観測は41→**48次元**（思想7次元追加）、LLMプロンプトには
「あなたの思想・ドクトリン」として明示され、報酬も軍事偏重で異なる（同じ状況でも
政府の性質が戦術を変えられる）。

### 宗教戦争 — 創発するイデオロギー圏（中立なモデル化）

実在宗教を実国に割り付けることはしない。代わりに**宗教系技術の普及が
イデオロギー圏を創発**させる（`tests/test_ideology.py` が検証）:

- 「AI神格宗教」を採用した国は `ai_cult` 圏へ、「テクノ・ナショナリズム」採用国は
  `techno_nationalist` 圏へ移行する（t15/t18以降に創発）
- **異なる圏の間は緊張+0.12、同じ圏の内側は-0.06**（圏の結束）。
  さらに異圏の最も敵対的な相手への信頼が毎月徐々に削れる（慢性的な摩擦）
- 異圏の間で開戦した場合、`war_start` イベントは **`ideological: true`**
  フラグと「イデオロギー圏の対立が背景」を伴う — 宗教戦争が統計として識別できる
- 内戦(`insurgency`)・思想(`doctrine_*`)・イデオロギー(`ideology`)の3層で、
  価値観に起因する紛争の全体をカバーする

実験・訓練では `hours_per_tick=720`（1tick=1ヶ月）の**圧縮時計**を使用する。
同じ実時間定数が刻み幅でスケールするだけで、別のモデルではない。

### 自国通貨建て債務の校正（現実照合: 危機でも主要国は破綻しない）

現実の長期の海峡封鎖・原油高騰はデフォルトを生んでいない。破綻するのは
外貨建て債務と外貨準備枯渇に挟まれた新興国（スリランカ2022年型）だけである。
これをモデル化するため国家は**自国通貨建て債務割合**（`local_debt_share`、
経済規模と金融ハブ性から導出）を持つ:

- 自国通貨分の金利負担は強制力が **×(1−0.8×share)** に減衰する（通貨発行で返済できる）
- 高債務時の赤字は通貨発行で吸収される（**インフレ**として現れる — 現実どおり）
- 信用リスクプレミアムの吹き上がりも share で抑制される
- 外貨準備が厚い間（≥2ヶ月分）は破綻ハザードが**×0.35**に低下し、防衛コストで準備が削れる

検証（earth_all 72ヶ月）: 基準世界の破綻は**スーダンの反復再建構のみ4件**。
18ヶ月のホルムズ封鎖でも破綻は**8件に集中**（スーダン・コートジボワール・
ミャンマー・ベネズエラ）、主要国の危機は**債務蓄積（平均債務 98→105%GDP）と
インフレ**として吸収される — 「原油高騰で破綴国家続出」という旧バージョンの
非現実を排除した。

## 研究問い（本作の核心）

**AI意思決定者は危機の安定性を変えるか。抑止はAI相手でも機能するか。**

国家の意思決定ループにAIが入ることで危機が制御不能なエスカレーションを起こすか、
という安全保障上の最重要懸念は、実世界では観測も実験もできない。
本作は**危機を完全に固定し、意思決定層（ルールAI/学習AI/思考AI）と抑止構成だけを交換する**
ことで、この問いに交絡ゼロで答える実験基盤を提供する。

**主要な結果**（10 seed、72ヶ月、混沌シナリオ固定、`analysis/out/stability_*.csv`、実時間校正後・動員ラダー込み）:

| 抑止構成 | ルールAI | 学習AI | 思考AI |
|---|---|---|---|
| 核なし | **218.6件** | **164.3件** | — |
| 現状(9カ国) | 108.7件 | 72.0件 | 20件† |
| 拡散(+IRN/KOR/SAU) | 49.5件 | **5.7件** | — |

- **抑止は強力に機能し、AI相手でも崩れない**: 核なし→現状→拡散で戦争は 218 → 96 → 39（ルールAI）に単調減少、
  **全構成で核保有国が当事者の戦争はゼロ**（抑止は「標的の選択」を変える）
- **拡散抑止の下では学習AIが際立って安定化する**（49.5 → 5.7件、初回開戦 t15 → t60）—
  均衡の構造を学んだ戦術層はエスカレーションを回避する。核なき世界ではその差は縮まる（219 vs 181）
- **思考AI（GLM）は初回開戦が遅い**（t4 → t5、戦争数は同等）— 協調的な外交判断が危機の起点を遅らせる（3seed・予備的観察）

→ **意思決定AIのリスク議論は「AIの性質」単独でなく「構造との相互作用」に焦点を当てるべき**
（学習AIは抑止構造が強いほど安定に寄与する）という分離を実証した。詳細は [危機安定性実験](#危機安定性実験q1q2-ai意思決定者と抑止の相互作用)。

> ⚠️ 本シミュレーションは公開されている概算データに基づく中立・分析目的のものです。特定の国・個人の標的化を意図するものではありません。地図データはNatural Earth（パブリックドメイン）を使用しています。

## コンセプト

- **神（プレイヤー）は国家を運営しない。** 介入カードと環境スライダーで世界の初期条件・パラメータを歪めるだけ
- 国家AI（**学習AI（既定・全国家へ汎用戦術AIを適用）** / 思考AI(LLM)）が生存をかけた対応を行う
  （ルールAIはUIから廃止。安定性実験の比較基線としてCLIにのみ残る）
- **介入1件が連鎖（カスケード）を生み、どの介入点が何を変えるかを反実仮想（A/B）で計測できる**

例（実世界プリセット、36ヶ月、seed=42、`server/logs/*_v2` の実ログ、実時間校正後）:

| 指標 | baseline | ホルムズ封鎖 | 台湾海峡封鎖 | 三重危機 |
|---|---|---|---|---|
| 世界GDP | 90.7 | 78.8 (**-13.2%**) | 79.4 (**-12.5%**) | 70.7 (**-22.1%**) |
| エネルギー価格 | 1.00 | **1.47** | 1.00 | **2.53** |
| 半導体価格（ファブ減産連鎖） | 1.00 | 1.45 | **1.67** | 1.45 |
| 食料価格 | 1.00 | 1.00 | 1.00 | **1.78** |
| デフォルト | 1件 | 6件 | 5件 | 8件 |
| 平均失業率 | 8.7% | 8.8% | 10.9% | 11.7% |

**封鎖する場所が効く商品を変える**: ホルムズ=エネルギー危機、台湾海峡=半導体ショック
（連鎖する失業を伴う）、三重封鎖は全部（エネルギー2.53倍・食料1.78倍）。

### IF史モード — 「過去、●●年に△△していたら」

決定論エンジンなので、**記録済みの歴史を過去のtickまで巻き戻し、介入を1つ差し込んで再実行**できます。
分岐tickまでは元の歴史とbit等価、以降が新しい歴史になります（A/Bは「最初から介入あり/なし」、
IF史は「歴史の途中で書き換え」の反実仮想）。

```bash
# 例: 金融危機の歴史で「t6（日本のデフォルト直前）に救済していたら」
uv run python -m terrarium.runner.whatif \
    --base earth_earth_financial_crisis --tick 6 --iv bailout:nation=JPN
```

実測（`whatif.json` に機械可読な分岐レポート）:

```
IF: t6 で日本を救済していたら
歴史が分岐した最初のtick: t6
最終差分: GDP +26.3 / デフォルト -2 / 戦争 ±0
元の歴史でだけ起きた: t7 JPN破綻 → t12 EU破綻（感染）→ t20 JPN再破綻 → t22 米国破綻
IF世界で新たに起きた:   t9 JPN破綻（債務252%は一度の救済では足りず）・t31 JPN破綻
```

→ **救済は日本の破綻自体は防げなかったが、EU・米国への感染の連鎖を断ち切った**。
「最後の貸し手」の効果は破綻件数ではなく感染経路の遮断にある、という示唆が読み取れる。

**ビューアからも**（神サーバ経由で `http://localhost:8788/static/web/viewer.html?replay=...` を開き「⏪ IF史」）:
分岐tickと介入カードを選ぶと神サーバが再実行し、分岐レポートとIF世界のリプレイを返します。
`run.json` の `config` に元runの (preset, policy, scenario) が記録されるため、IFは自動で同じ条件下から分岐します
（LLM run は非決定論的なため mock_llm にフォールバック+警告）。

### 既定の世界: earth_all（全世界176カ国）

**UIの既定はこの176カ国世界です**（16カ国版 `earth` はCLI専用に残し、コミット済み実験の
再現にのみ使用）。**Natural Earth の全特徴を1国1国家AIとして手続き生成**します。

**初期値は実データ**（`world/wb_data.json`、`scripts/fetch_wb.py` で世界銀行APIから
取得・コミット済み。APIキー不要、取得時のスナップショットなのでオフライン再現可）:

| 項目 | ソース | カバー率 |
|---|---|---|
| GDP・人口・失業率・人口成長率 | 世界銀行 WDI（+Natural Earth埋め込み推定をフォールバック） | 177/177 |
| 債務対GDP（中央政府） | 世界銀行 GC.DOD | 93/177 |
| 軍事費対GDP（→軍事力スコア、米国=100に較正） | 世界銀行/SIPRI | 157/177 |
| ジニ係数・再エネ比率 | 世界銀行 | 153-169/177 |
| 政治の安定（WGI推定→安定度0-100） | 世界銀行 ESG/WGI | 165/177 |

実測の検証: 世界GDP合計 **117兆USD（開始時）**、日本の債務 **252%**、ソマリアの
WGI安定 **23/100**・失業 **18.9%**、ノルウェーの再エネ **61%** — すべて実データそのまま。
手概算テーブル(DATA)と決定論的導出は欠損国のフォールバックとしてのみ残る。
攻撃性・疑心・資源構造は引き続き公開情報の簡易表現（中立的・分析目的）。
需給は全体で需要×1.15以上になるようトップアップされ、航路（~660本）は
実際の海峡を経由して自動生成されます。

```bash
uv run python -m terrarium.runner.headless --preset earth_all --seed 42 --ticks 12     --policy mock_llm --scenario scenarios/earth_hormuz.yaml
uv run python scripts/fetch_wb.py    # 実データの再取得（スナップショット更新）
```

- 全主体がそれぞれ予算・外交・軍事姿勢を決定する「本当の世界シミュレーター」
- 176カ国×664航路でも **~70ms/tick**（リアルタイム再生可）
- 同じseedで常に同一の世界（決定論）。16カ国版 `earth` は提出実験の再現用に温存

**earth_allでの封鎖実験**（seed=42, 24tick, `logs/earth_all_*`）:

| 指標 | baseline | ホルムズ封鎖(18ヶ月) | 差分 |
|---|---|---|---|
| 世界GDP（開始時117兆USD＝実データ） | 126.7 | 122.5 | **-3.3%** |
| デフォルト（外貨建て新興国に集中） | 4件 | **8件** | +4 |
| 平均債務対GDP | 98% | **105%** | **+7pt**（危機は債務とインフレで吸収） |

176カ国世界では封鎖の金融感染が**途上国を中心に5倍のデフォルト波**を起こす

### 世界の自動生成（プロシージャル生成）

実世界プリセット（`presets/earth.yaml`: 実在16主体・実在海峡・シーレーン）に加え、
シードから**需給バランスの取れた架空世界を実地図上に自動生成**できます。

```bash

# 生成世界でシミュレーション（A/Bも --gen-seed を揃えれば同一世界で比較可能）

    --policy mock_llm --scenario scenarios/gen_chokepoint.yaml
```

生成器の性質（`src/terrarium/world/worldgen.py`）:
- **決定論**: 同じ `(seed, nations, chokepoints)` → 同じ世界（テスト担保）
- **需給バランス**: 全商品で世界供給 ≥ 需要×1.15になるよう資源ユニットを自動割当。神が介入しない限り経済は自然崩壊しない

- 架空国家の重心は GeoJSON の**陸上ポリゴン内からサンプリング**（南極除外）、航路は実在海峡（ホルムズ・マラッカ・台湾海峡・スエズ等）経由で張られる
- シナリオでは国家・海峡を `#0`（ソート順インデックス）でも参照可能。生成世界でも汎用シナリオ（`scenarios/gen_*.yaml`）が動く

## 非決定戦略因子: 核保有のデータモデル（FactorSpec）

「核は保有国にしか許されない」「放棄も新規保有も戦略」のような**国家AIの自己選択で動く
離散的ケイパビリティ**は、`world/factors.py` のデータモデルで定義します（エンジン非依存）:

```python
FactorSpec(
    id="nuclear", name="核兵器",
    acquisition_ticks=18,               # pursue表明から取得までの期間
    prerequisites={"military": 40, "stability": 45},   # 取得の前提
    initial_holders=[...],              # NPT的な既存保有国（プリセットで指定）
    deterrence_vs_nonholder=0.15,       # 非保有国→保有国への開戦意欲係数
    deterrence_mutual=0.03,             # 保有国同士（MAD）
    military_mult=1.15, pursuit_cost_gdp=0.002,
    abandon_stability_hit=8.0, abandon_trust_gain=6.0,
)
```

運用のプロトコル（全policyで共通）:
- 国家AIは毎tick **`doctrines: {nuclear: pursue|hold|abandon}`** を意思決定に含める
  （heuristic=脅威/体制崩壊への反応、LLM=プロンプトで選択、RL=行動空間に拡張可能）
- エンジンは **取得進捗(0-100%)を積算**（前提を満たし追求した場合のみ）、100%で保有へ遷移し
  `factor_acquired` イベント（因果parent付き）、**3tick継続した放棄表明**で放棄し
  `factor_relinquished`（国内安定打撃+他保有国からの信頼回復）
- **抑止**: 保有国への開戦意欲は×0.15、保有国同士は×0.03（MAD）
- 神は `grant_factor`（既成事実化）も可能

現在4因子を実装済み（いずれもCATALOG定義のみで追加）:

| 因子 | 戦略的意思決定 | 効果 |
|---|---|---|
| `nuclear` 核兵器 | 脅威時にpursue（18tick） | 抑止（対非保有×0.15/相互×0.03）・軍事×1.15 |
| `nuclear_umbrella` 核傘 | **核保有国と同盟**で加入（2tick） | 保護国の抑止を**0.75×で継承**（拡大抑止） |
| `export_control` 輸出規制 | 制裁対象/大国/戦時が加盟（4tick） | **加盟国の制裁がレジーム全体へ伝播**（集団制裁） |
| `currency_bloc` 通貨ブロック | 大国・準備枯渇国が加盟（6tick） | **為替感応度半減・準備流出0.7×**（決済網） |

新しい因子（共通防衛条約、資源カルテル…）も **CATALOG に FactorSpec を1つ足すだけ**。
エンジン・UI・ログ・IF史は一切変更不要です。実測では、脅威を受け前提を満たした国が
約18tickで取得に至り（テスト担保）、これらの離散遷移もparentリンク付きで因果グラフに乗ります。

## LLM→RL蒸留: 思考AIが教師となり学習AIを訓練する

**「最先端のLLMが自律訓練する」の実体**（`terrarium/rl/distill.py`、
`tests/test_distill.py` が検証）:

1. **収集** — エンジン内でLLM（z.ai GLM）政府を運転し、(観測48次元 → 決定) を
   教師データとして記録（`models/llm_teacher_data.jsonl`）
2. **蒸留** — 軽量RLネット（numpy MLP・30KB）が行動クローニングでLLMの戦術を模倣
3. **微調整** — 自己対戦actor-criticでLLMの戦術を出発点に改善

実測（**glm-5.3**（z.ai、`.env`の`ZAI_MODEL`）、5カ国×24決定=118回の実API呼び出し、各〜23秒）:
- 行動クローン **15エポックで予算一致率86%**（チャンス水準17%）— LLMの予算配分の
  「癖」が30KBのネットに移植される
- 評価報酬: BC 78.4 → **BC+A2C微調整 100.0**

LLM 1回の推論は数十秒だが、蒸留後の戦術AIはnumpy/CPUで即時に動く —
**LLMの戦略判断を、LLMなしで動く全国家に配布する**パイプラインである
（実行: `uv run python -m terrarium.rl.distill --preset earth --episodes-per-nation 1`）。

> 運用上の注意: APIキーが無いプロセスではLLMはheuristicに静かにフォールバックする。
> これを検出するため `ZaiLLMPolicy` は `calls`/`fallbacks` を数え、蒸留は
> 実呼び出しゼロで即fail、稳定性実験は実行後に呼び出し比率を報告する
> （かつ `.env` を自動読み込みする — 過去のGLM安定性数値の一部はフォールバック
> 混入の疑いで再測定中）。

## 再帰型戦術AI（GRU: 時系列を統合する推論）

`--recurrent` で**GRU株+actor-critic頭**の再帰型戦術AI（LSTM相当）を訓練できる
（`tests/test_recurrent.py` が検証）:

- MLP版は毎tickの観測を独立に写像する（マルコフ前提）。再帰版は**隠れ状態hが
  エピソードを通じて過去の観渗・行動・報酬の影響を保持する** — トレンド特徴量に
  頼らず「危機の積み重ね」を自力で統合する
- 訓練は各エピソード終了後に系列を再前向播し、**打ち切り長16のBPTT**で逆伝播
  （numpy実装、CPUのみ・GPU不要）
- 実行時は政策オブジェクトの寿命の間隠れ状態がローリングし、世界再構築で
  ゼロに戻る — **決定論（IF史の再現性）を保つ**
- 実測: 乾魊シナリオのSAH学習で MLP(2000エピソードで+0.2) に対し
  **GRUは400エピソードで+2.9** — 履歴の統合が学習速度そのものを改善する
  （汎用訓練でもMLP+1.57に対しGRU+7.43〜+12.88）
- **ただし展開の分布シフトに弱い**: 16カ国地球で訓練したGRUを汎用AIとして
  176カ国世界に展開すると崩壊波を生む（訓練評価110でもearth_allで47カ国崩壊）。
  再帰は系列外挿を強めるため、分布の違いに敏感になる。MLPを汎用の既定とし、
  GRUは `models/generalist_gru.npz` に保存してある（単一国家の戦術AIとしては
  有効）

```bash
uv run python -m terrarium.rl.train --preset earth --nation ALL --recurrent \
    --scenario scenarios/earth_hormuz.yaml --episodes 4800   # → models/generalist.npz (GRU)
```

## 危機安定性実験（Q1+Q2）: AI意思決定者と抑止の相互作用

**研究問い**: 危機は固定したまま、意思決定層（ルールAI/学習AI/思考AI）と核保有構成
（なし/現状5カ国/拡散8カ国）だけを交換したとき、エスカレーションはどう変わるか。
決定論+同一シナリオ（earth_chaos）により、差分はその交換に純粋に帰属できる。

```bash
uv run python -m terrarium.runner.stability --policy heuristic --deterrence none --seeds 10
uv run python ../analysis/make_stability_fig.py   # → analysis/out/crisis_stability.png
```

**結果（10 seed、72ヶ月、earth_chaos 固定、earthプリセット、実時間校正後）**:

| 抑止構成 | ルールAI | 学習AI | 思考AI | 初回開戦(ルール/学習) |
|---|---|---|---|---|
| 核なし | **217.5±12.5 件** | **179.6±11.6 件** | — | t4 / t4 |
| 現状（9カ国保有） | 108.7±11.5 件 | 72.0±5.0 件 | 20件† | t4 / t4（GLM **t7**） |
| 拡散（+IRN/KOR/SAU） | 49.5±10.0 件 | **5.7±2.1 件** | — | **t15 / t60** |

- **核の有無がエスカレーションを桁で変える**（219 → 99 → 41、相互防衛と安全保障ジレンマ入りでも単調減少）。
  **全構成で核保有国が当事者の戦争はゼロ** — 抑止は「頻度」だけでなく「標的の選択」を変える
- **動員ラダーが統計に現れる**: 拡散抑止は初回開戦を t4 → t15（ルール）/ t60（学習）へ遅延させる。
  戦争は緊張が臨界を超えても即時勃発せず、動員（4-30日）とその解除（stand_down）を経る
- **学習AIは抑止構造が強いほど安定化に寄与**（拡散で49.3 → 6.6件）。核なき世界では差は縮む（220 vs 161）—
  戦術層は「均衡の簿記」を学び、抑止の傘の下でエスカレーションを回避する。
  **構造が支配するが、AIは構造を増幅も緩和もする**
- **思考AI（z.ai GLM）: 実API検証済みの再測定（1seed×24ヶ月、実行時間2.5時間=
  384回の実呼び出し）で 戦争20件・初回開戦 t7・核保有国が当事者の戦争ゼロ** —
  ルールAI(t4)より開戦が**一貫して遅い**（協調的な外交判断が危機の起点を遅らせる）。
  ※ 過去のGLM 3seed×72ヶ月の数値はAPIキー未ロードによるheuristicフォールバック
  混入の疑いで撤回し、フォールバック監視付きで再測定した（LLMは1呼び出し〜23秒・
  非決定論のため予備的観察として扱う）

## リアリズム層: 人口・労働・財政投資・為替・経常・CO2

国家は以下の**構造パラメータ**（NationSpec、プリセットで指定）を持ち、毎tickの力学に効きます:

| パラメータ | 効果 |
|---|---|
| `population_growth` 年率人口成長 | 人口が動態変化（戦争で減少） |
| `education` 教育水準 0-1 | 技術吸収速度・支持率の底上げ |
| `gini` 所得不平等 | 0.40超で安定を継続的に蝕む |
| `energy_renew` 再生エネルギー比率 | CO2排出量を決める（核融合普及で実効0.50へ） |

毎月次レートの力学（実時間校正: 全レートは1tickの実時間でスケールし、神モードの1時間刻みでも同一の物理が走る）:
- **失業率**: 生産ギャップ・戦争・財・サービス不足（レイオフ）で上昇、福祉予算で緩和（τ≈4ヶ月）。失業は成長・支持・安定を蝕む（スタグフレーションのチャネル）
- **インフラ指数**: 補助金予算シェアで蓄積（生産力倍率0.5-1.25）、戦争で毀損
- **為替**: インフレ差で調整、債務不履行で**30%暴落**。通貨安は輸入インフレを増幅（パススルーはCPI上限35%）
- **経常収支・外貨準備**: 航路フロー×価格で計上。準備<1ヶ月分で**外貨危機**（輸入絞り・スタグフレーション・イベント発火）
- **CO2**: 化石生産×(1−実効再生比率)が累積。全球CO2は食料収穫を最大15%毀損（気候チャネル）

実測（earth, seed=42, 36ヶ月、実時間校正後）: ホルムズ封鎖は平均失業率を **8.7%→8.8%**（台湾海峡封鎖は**10.9%**へ）、
デフォルトを **1件→6件**へ増やす。失業の応答はオークン則のτ≈4ヶ月で遅れて効く。

## 未来技術・宗教の創発（論文レベルの2026年以降）

シミュレーション内で時間が進む（実時間校正済み時計。神モード=1tick/時、実験=1tick/月、開始=西暦2026年8月1日）と、**研究フロンティアの技術が「論文→原型→普及」していく**（創発時期は月数で定義）。各国の導入確率は研究吸収能力（GDP・金融・半導体備蓄）に比例し、**技術格差が創発的に生じる**。

| 分類 | 技術（創発時期） | 効果 |
|---|---|---|
| 兵器 | サイバー攻撃基盤(t5)・自律ドローン群(t8)・高出力レーザー迎撃(t14)・極超音速迎撃網(t22) | 軍事力増強、不信・好戦性上昇 |
| 製造 | AI設計ファブ(t10)・バイオ製造(t16)・自己修復自動工場(t26) | 商品生産の倍率向上 |
| 資源 | 深海底鉱業(t12)・**核融合(t20)**・宇宙太陽光(t24)・小惑星採掘(t30) | **油田ゼロの国にも電力を与える**（flat供給）、軌道価値上昇 |
| 宗教・社会 | **AI神格宗教(t15)**・テクノ・ナショナリズム(t18) | 安定・世論上昇、但是他国との信頼低下（イデオロギー摩擦） |

神の新カード: `grant_tech`（技術の授与）と `ban_tech`（全世界での研究禁止）。

**創発的な洞察（seed=42, 36ヶ月、実ログ・実時間校正後）**: 同じホルムズ封鎖履歴を分岐させて核融合だけを禁止すると（IF史 t1、分岐まではbit等価）、CO2累積排出は **581 → 626 (+7.8%)** 増え、戦争は+2件、日本の債務不履行は t25→t23 に**前倒し**される — **未来エネルギー技術の創発は気候・紛争・債務経路のすべてを変える**（決定論的な因果比較）。

## 財政・金融システム（債務不履行と感染の連鎖）

国家は**債務（対GDP比）と信用**を持ち、財政収支（税収 vs 軍事費〔戦時2倍〕＋福祉＋利払い、四半期スケール）で債務が蓄積する。債券金利は「基準2%＋信用リスクプレミアム（信用低下で最大+10%）＋インフレ連動＋**神の利上げ**」で決まり、**利払いが対GDP比月1.5%超で確率的（月次ハザード）、3%超で確定的に債務不履行（sovereign_default）**となる。

デフォルトの効果: 通貨暴落（インフレ+15pt）・信用5%・債務半減（リストラ）・緊縮予算の強制 — そして**債権国（金融ハブ）が損失を被り信用が毀損（credibility_hit、因果parentリンク付き）→ 感染の火種**。再建モラトリアム（12ヶ月）で即死は防ぐ。

神の新カード: `bailout`（救済: 債務40%削減・信用回復）/ `rate_hike`（世界金利引き上げ＝全債務国への一斉圧迫）。

**金融感染の実測**（`earth_financial_crisis` = ホルムズ封鎖＋利上げ8%、seed=42、
自国通貨建て校正後）: デフォルトは **1件**（日本が利払い負担で限界到達、t17）にとどまる。
主要国の危機は破綻ではなく**債務蓄積とインフレ**として現れる — 現実の原油危機の
パターンと一致する。破綴の連鎖を見るには外貨建て条件を重ねる必要がある
（earth_allでは封鎖下でもスーダン・コートジボワール・ミャンマー・ベネズエラに集中）。

## 外交の記憶: 過去の会話と経緯を振り返る

国家AIは**エピソード記憶**を持つ（`tests/test_memory.py` が検証）:

- **双方向の外交・紛争履歴**（`view.memory`）: 脅迫・制裁・同盟・貿易協定・開戦・
  講和・軍備管理・偽情報の直近**5年間**（上限20エピソード）を「誰が何をしたか/
  されたか（`i_acted`）」付きで思い出す。**記憶の窓は実時間で定義され、
  時計モード（週次閣議でも月次でも）に依存しない** — 政府は決定周期ではなく
  歳月で覚える（`test_memory_window_is_realtime` が検証）。LLMのプロンプトには「あなたの外交・紛争履歴」と
  して明示され、過去の経緯を踏まえた判断ができる
- **自分の政策の履歴**（`view.last_decisions`）: 直近**24ヶ月**の決定（予算・姿勢・
  配給、上限12件）。一貫性や路線転換の材料になる
- heuristicも記憶を使う: 直近6ヶ月に脅迫・偽情報の標的にされた国は防衛予算を厚くする
- RL観測は次元を固定しているため、記憶は信頼度・トレンド（48次元の状態量）に
  圧縮されて供給される — LLM（会話型）とRL（状態型）で記憶の持ち方が異なる

## リッチ観測: 戦略推論には渡せるもの全部を渡す

国家AIの意思決定入力（`NationView`）は現在値のみならず、**利用可能な情報の全体**を含みます:

| 入力 | 内容 |
|---|---|
| 時系列トレンド | 各商品価格の t-1/3/6/12比、自国のGDP・安定・失業・債務・為替・準備の変化率、**信頼の変化（±3以上の相手上位）** |
| 世界情勢 | 世界GDPとt-12比、平均失業、全球CO2、進行中の戦争一覧、**核保有国リスト** |
| 貿易構造 | 商品別の輸入依存度、**海峡別の曝露（「エネルギーの80%がホルムズ経由」）**、主要供給国/顧客の構成 |
| 他国の観測可能な概要 | 信頼・同盟・戦争・制裁に加え GDP・軍事・安定・核保有（大世界では関連上位30カ国に圧縮） |
| 直前の自分の決定 | 前月の予算・姿勢・配給・doctrine — **無記憶なLLPに一種の記憶を供給** |
| イベント系列 | 直近16件を `t14: ...` と**tick付き**で（時間的文脈） |

実例（ホルムズ封鎖下の日本がt15に観測するもの）: エネルギー価格 **+42.5% (vs t12)**、自国GDP **-51.9%**、
失業 **+227%**、海峡曝露 ホルムズ0.80/マラッカ0.80/台湾0.60、直前の自分の決定（備蓄0.33・防衛姿勢・核追求）。
LLMはこれら全部をJSONプロンプトで受け取り、次月の戦略を推論します。
heuristicは既存の挙動を維持（コミット済み実験の再現性は不変 — 実測で系列bit等価を確認）。

## 複合戦略AI: LLM（戦略層）× 強化学習（戦術層）× ルール（世界解決層）

| 層 | 担当 | 実装 |
|---|---|---|
| **戦略層** | 外交・軍事姿勢・配給/プロパガンダ判断、自然言語の理屈 | LLM (z.ai/GLM, OpenAI互換) |
| **戦術層** | 毎月の予算配分（6プリセット）・姿勢・配給の微決定 | **強化学習** (numpy実装Actor-Critic, MLP) |
| **世界解決層** | 市場・物理・連鎖の決定論的解決 | ルールベース・エンジン |

RLは**DLフレームワーク非依存のnumpy実装**（Actor-Critic + Adam + エントロピー正則化）。依存軽量・CPUで高速・bit再現可能:

```bash
# 学習（例: 脆弱な新興国 SAH を旱魃ストレス下で2000エピソード）
uv run python -m terrarium.rl.train --preset default --nation SAH \
    --scenario scenarios/drought_sahelia.yaml --episodes 2000 --out models/rl_SAH_drought.npz

# 学習済み戦術層でシミュレーション
uv run python -m terrarium.runner.headless --preset default --policy rl \
    --rl-nation SAH --rl-weights models/rl_SAH_drought.npz --scenario scenarios/drought_sahelia.yaml

# ハイブリッド（LLM戦略 × RL戦術。ZAI_API_KEY必要）
uv run python -m terrarium.runner.headless --preset default --policy hybrid \
    --rl-nation VLT --scenario scenarios/chokepoint_closure.yaml

# 比較実験（heuristic vs RL vs hybrid、複数シード）
uv run python -m terrarium.runner.compare_policies --preset default --nation SAH \
    --scenario scenarios/drought_sahelia.yaml --seeds 5 --with-hybrid
```

**実測**（学習曲線は `models/*.curve.json`、重みは同梱。観測は41次元=状態26+トレンド15）:
- 学習評価報酬: SAH（旱魃下）**-172.3 → -137.4 (+34.9)**、VLT **-19.2 → +3.3 (+22.5)** — 脆弱国家の生存戦略を獲得
- 自己対戦: EGY（金融危機下）**-85.7 → -45.1 (+40.6)**、USA **+6.5 → +8.3**、CHN **-0.2 → +1.1**
- 36tickの最終指標では手調整heuristicと**互角**（崩壊率0%を維持）— RLはドクトリンを書かずに同等性能へ到達
- ハイブリッド実走行の思考例: 「半導体を交渉カードにエネルギー供給源を分散確保。備蓄最優先の防衛態勢」（LLM戦略）×「予算=stockpile」（RL戦術）

### 自己対戦（マルチエージェントRL）

`--nation` にカンマ区切りを渡すと**複数国家の戦術層が同一世界内で同学習**します
（他方の学習者は自分の環境の一部 → 固定heuristic相手への過適合を避けた戦術の共進化）:

```bash
# 米中の戦術層をホルムズ封鎖下で自己対戦学習
uv run python -m terrarium.rl.train --preset earth --nation USA,CHN \
    --scenario scenarios/earth_hormuz.yaml --episodes 1500 --out models/selfplay_earth
# → models/selfplay_earth_USA.npz / _CHN.npz / selfplay_earth.curve.json

# 学習済み自己対戦ペアでシミュレーション（両国ともRL戦術）
uv run python -m terrarium.runner.headless --preset earth --policy rl \
    --rl-nation USA,CHN \
    --rl-weights models/selfplay_earth_USA.npz,models/selfplay_earth_CHN.npz \
    --scenario scenarios/earth_hormuz.yaml
```

### 実測: 自己対戦と「介入点の階層性」

- 自己対戦学習（トレンド観測込み）: **EGY +40.6 / JPN +3.6**（金融危機下）— 脆弱な債務国ほど学習利得が大きい
- **報酬設計も介入点**: `--default-penalty`（自国デフォルトへの報酬ペナルティ）で
  「成長最適化」vs「債務規律」の目標を切り替えられる
- **正直な結果**（`earth_financial_crisis` 下、seed=42）: RL戦術層は予算ドクトリンを
  変える（heuristic: 福祉35/備蓄1・防御20tick → RL: 福祉36・中立36）が、
  債務252%+封鎖+利上げ8%という**構造的デフォルトは国内予算配分では防げず、
  連鎖は不変**（JPN t7 → EUR t12 → JPN t20 → USA t22）。
  連鎖を変えたのは**神のベイルアウト**（デフォルト4件→3件）—
  **戦術層（国家AI）・戦略層（LLM）・神（プレイヤー）の介入階層において、
  構造的危機を断てるのは神の介入のみ**という本作テーマの裏付けになった
