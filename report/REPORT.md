# Geopolitics Terrarium — 技術報告書

第2回 AIエージェント社会シミュレーション・ハッカソン「メタ安全保障」応募作品の
完全な技術報告書である。READMEは利用者向けの圧縮版、本書は審査・検証者向けの
完全版である。本書のすべての数値は、コミット済みのログ・CSV・スクリプトから
再現できる(§8に表ごとのコマンド)。

---

## 1. テーゼと研究問い

**テーゼ**: 全国家安全保障シミュレーター。Natural Earthの全特徴(176カ国)を
AI国家化し、相互防衛・安全保障ジレンマ・核抑止・情報の霧・政体・思想を含む
力学の下で、危機の安定性を「意思決定層の交換」と「抑止構成の交換」によって
測定する。パラメタが足りなければ足す — ただし足したパラメタの来歴を
グレード付けし、同定されない自由度を明示する。

**研究問い**:

- **Q1**: AI意思決定者(ルール/学習/思考)は危機の安定性を変えるか
- **Q2**: 抑止(核保有構成)はAI相手でも機能するか

検証原理は**層交換**にある。危機(シナリオ・seed・時計)を完全に固定し、
(1)意思決定層だけ、(2)核保有構成だけを交換する。決定論エンジンなので、
差分はその交換に純粋に帰属し、測定の交絡はゼロになる。
これは社会シミュレーションでは通常不可能な統制(実世界では観測すらできない)
であり、本作の中核的方法論的貢献である。

**主張の規律**(§7に詳細): 本作の数値は相対比較(A/B・IF・多seed)の根拠として
有効であり、絶対水準の現実予測としては無効である。

## 2. システム構成

### 2.1 三層アーキテクチャ

| 層 | 実装 | 規模 | 役割 |
|---|---|---|---|
| 戦略層 | LLM(z.ai glm-5.3、OpenAI互換) | API | 外交・軍事姿勢・配給の判断と自然言語の理屈 |
| 戦術層 | 強化学習(numpy A2C、MLP/GRU) | 3,408〜19k params | 毎期の予算配分・姿勢・配給 |
| 世界解決層 | 決定論ルールエンジン | ~2,000行 | 市場・物理・財政・戦争・気候の因果 |

決定論性: エンジンの乱数はseed付き単一RNGで、国家・航路の走査順は常に
ソート順。`(seed, spec, policies, scenario)`が同一なら結果はbit等価である
(`tests/test_determinism.py`, `test_hourly_clock_is_deterministic`)。
この性質がIF史(過去tickへの介入差し替え)とA/Bの信頼性の基盤になる。

### 2.2 シミュレーション時計(実時間校正)

すべての動力学は**実時間(時間)**で定義され、1tickの実時間
(`hours_per_tick`)で刻まれる。神モード(ライブ)は1時間/tick、
実験・訓練は720時間(=1ヶ月)/tickの圧縮時計を使う。**同一の物理が
刻み幅でスケールするだけで、別のモデルではない。**

主要な時定数と遅延(`world/clock.py`、来歴は§5):

| プロセス | 値 | 来歴 |
|---|---|---|
| 価格発見 | τ=24h | A: 1990湾岸危機にフィット |
| 航路封鎖の実効化 | τ=120h | A: 同上(海運見積り2-4週との乖離は記録済み) |
| 再開後の回復 | τ=2160h | A: 戦争リスクプレミアムの残留 |
| インフレ期待 | τ=4430h | C(旧月次校正との互換値) |
| 失業(オークン則) | τ=16000h | B: 2008年米国経路にフィット |
| 戦争の動員 | 4〜30日(最頻10日、三角分布) | C: 概算 |
| 同盟参戦の協議 | 1日〜1週 | C |
| 政府の意思決定周期 | 168h(神モード) | 設計値: 政府は毎時間閣議を開かない |

介入の伝播(実測、ホルムズ封鎖): 1〜3日で期待による価格急騰 → 2〜4週間で
実物の輸送力低下 → 備蓄揚耗の2〜3ヶ月後に不足とデフォルト → その先で動員と
戦争。3日間の観測では価格以外は何も壊れない(`tests/test_clock.py`がこの
約束を検証する)。

### 2.3 市場と物流

- 封鎖は即時に輸送力を殺さない: 航行中の船はまだ到着するため、実効輸送力は
  τ=120hで漸減する(throttle)。回復は90日(リスクプレミアムの残留)
- 価格は需給の不足(scarcity)と物流遮断(shock)の関数に、**期待効果**
  (封鎖ニュースが載せるfearプレミアム、τ=72hで減衰)を加えた目標へ
  τ=24hで緩和する。遮断強度は世界需要でなく**航路需要に対する比率**で
  測る(世界需要で割ると地域危機が全部薄まるため)
- 輸出はGDP水準ではなく**成長率ボーナス**(最大+2.4%/年)として効く。
  水準加算は資源輸出国の複利爆発を生む(開発中に発見・修正されたバグ、§6)

### 2.4 財政と金融

- 債務は財政収支(税率30%−軍事〔戦時2倍〕−福祉−利払い、四半期スケール)で蓄積
- 債券金利 = 基準2% + 信用プレミアム + インフレ連動 + 神の利上げ
- **自国通貨建て債務**(層2、§4): 金利負担の強制力は外貨建て分にのみ働き、
  自国通貨分の赤字は通貨発行(インフレ)で吸収される。外貨準備≥2ヶ月分の
  間は破綻ハザード×0.35(準備防衛)
- 輸入インフレのパススルーはCPI上限25%に正規化(B: 1973-74年CPI+4.8ptに較正)。
  5商品依存度の単純和は二重計上になる(開発中に発見・修正、§6)
- デフォルトの効果: 通貨暴落・債務半減(リストラ)・緊縮の強制・債権国への
  感染(credibility_hit、因果parentリンク付き)

### 2.5 国家AIの観測と記憶

観測(NationView)は「渡せるもの全部」: 現在値に加えて時系列トレンド
(価格・自国指標のt-1/3/6/12比)、貿易構造(輸入依存・海峡曝露・主要供給国)、
世界情勢、他国の観測可能概要(fog_of_warで信頼推定を平均へ退行)、
直近のイベント系列。RL観測は48次元(状態26+トレンド15+思想7)に圧縮。

記憶は実時間で定義される(時計モードに依存しない):
- **外交・紛争のエピソード記憶**: 直近5年間・上限20件、`i_acted`フラグ付き
  (「誰が何をしたか/されたか」— 脅した側と脅された側で記憶が違う)
- **政策の履歴**: 直近24ヶ月・上限12件

### 2.6 思想・政体・イデオロギー

| 層 | パラメータ | 初期化 | 効果 |
|---|---|---|---|
| 思想 | 危機許容/軍事偏重/修正主義/報復性/同盟遵守 | 軍事偏重は実軍事費比率から導出、他は決定論サンプル(中立的様式化) | 緊張・軍拡反応・降伏閾値・条約履行・RL報酬・LLMプロンプト |
| 核態勢 | counterforce/MAD/NFU | 軍事偏重から導出 | 抑止係数×0.75/1.0/×1.25 |
| 政体 | 民主/混合/専制 | **WGI発言権2024実データ**(民主40/混合64/専制72) | 選挙サイクル・民主的平和・抑圧・被害感度 |
| イデオロギー | 世俗/ai_cult/techno_nationalist | 宗教系技術の採用で創発(実在宗教の割付はしない) | 圏間摩擦(+0.12)/圏内結束(−0.06)、ideological戦争フラグ |

制度的制約: **予算の慣性**(政府は一期に±15pt以上予算を振れない — 学習AIも
この制約下で学習する)、**制裁の経済的歯**(被制裁数×0.4%/年の成長ドラッグ)、
**囮戦争の誘因**(選挙直前・低支持の民主政権は攻撃性が高まる)。

### 2.7 戦争

戦争はスカラーではなく**エスカレーションラダーと強度**を持つ:

1. 緊張が閾値を超えると`mobilization`(動員、4-30日の物理)。即時開戦しない
2. 動員完了時に緊張が残っていれば開戦、引けていれば`stand_down`
3. 開戦後、強度は1.0(限定戦争)から軍事偏重で最大3.0(総力戦)へ漸増。
   消耗・GDP損失・**人的被害**(人口簿記、v7基準世界で累計137万人)が強度でスケール
4. 終結は3通り: 交渉による講和(Fearon型: 力の差と疲弊で成立、強度が高いほど
   講和圧力が増す)、軍備管理条約(核保有国同士の消耗戦)、消耗衰亡
5. 民主政体は人的被害に敏感(疲弊×1.2 — 死者の民主的費用)

同盟: 相互防衛は信頼に応じて1日-1週の協議の後に履行される(遵守度は
`treaty_fidelity`)。安全保障ジレンマ: 信頼<15の敵対大国の軍事優位(>1.2×)が
攻撃性を駆動する。核拡散連鎖: 敵性核保有国の出現が対抗核追求を誘発する。

### 2.8 追加の因果ファクター(v8)

5つの連鎖を追加した(`tests/test_causal_factors.py` が各々を検証):

1. **難民フロー**: 戦争の強度に比例した人口流出(0.08%/月×強度)が、重心距離の
   近隣3カ国に受け入れ負担(安定−、失業+)として波及する。実測: 176カ国基準世界
   の72ヶ月で114.8百万人の移動(現実の全世界強制移動~110Mと同オーダー)、
   受入は紛争隣接国に集中。戦争の「外部不経済」が地理的に伝播する初の経路
2. **政体遷移**: 2年間の統治危機は混合政体を権威主義化し、3年間の繁栄と教育は
   専制を民主化する — 政体が外生パラメータでなくシステム内生の状態になった
3. **気候極端イベント**: CO2累積に比例した旱魂/台風ハザード。慢性の食料減産に
   加えて急性の気候シグナルが入った
4. **エネルギー転換**: 価格シグナルと補助金が再エネ比率を漸増させ、CO2排出を
   経時的に削減する — 危機が長期の需給構造を変える(1973年後の省エネ)
5. **サイバー戦**: サイバー攻撃基盤の保有国は戦時に敵の半導体生産(×0.7、2ヶ月)
   と軍事系統を妨害する

## 4. 学習AI

### 4.1 基本スタック

numpy実装のアクタークリティック(A2C)。MLP(3,408 params、6予算プリセット×3姿勢×
2バイナリの離散行動)を既定とし、GRU再帰型(隠れ状態で系列を統合、エピソード
BPTT打ち切り長16)も選べる。DLフレームワーク非依存(CPUのみ・bit再現・
審査員が全勾配を読める)。自己対戦(複数学習者が同一世界で共進化)と、全国家を
巡回して重みを共有する**汎用戦術AI**(generalist)の訓練に対応する。

### 4.2 テーゼ対応スタック(generalist_lh / generalist_fine)

| 要件 | 実装 | 根拠 |
|---|---|---|
| 長期戦略 | 訓練地平96ヶ月 + GAE(λ=0.95) | MC戻り値からTD偏差混合へ置換 |
| 微操作 | 予算4軸×5水準(625通り) | ドメイン内で学習加速 |
| 分布シフト耐性 | ドメインランダム化(earth+生成世界3種の巡回) | 16→176カ国転移の破綻を解消 |

転移評価(訓練に未使用のearth_all・ホルムズ72ヶ月):

| 指標 | earth専修 | lh (GAE+DR) | +fine |
|---|---|---|---|
| 世界GDP | 121.2 | **124.8** | 120.5 |
| 平均失業率 | 5.4% | **3.3%** | 4.4% |
| 崩壊(最終) | 9 | 10 | **45(悪化)** |

**知見**: 微操作はドメイン内で有利だが分布シフト下で転移を悪化させる
(行動空間の細分化が過適合の自由度を増す)。要件間のトレードオフ自体を
測定した。GRUも同様: 単一国家では400エピソードで+2.9(MLPの2000エピソード
+0.2を大きく上回る)が、16カ国訓練→176カ国展開で47カ国崩壊の分布シフトを
起こした。汎用配備はlh(粗行動)、GRU/fineは効果と限界の実証として同梱する。

### 4.3 LLM→RL蒸留(`rl/distill.py`)

glm-5.3政府を運転して(観測48次元→決定)を教師データとして収録し、30KBの
numpy MLPが行動クローニング(15エポックで**予算一致率86%**、チャンス17%)、
A2C微調整で評価報酬78.4→100.0。LLMの1推論は数十秒だが蒸留後は即時動作する —
**思考AIの戦術をLLMなしで全国家に配布する**パイプライン。

### 4.4 実験の健全性監査

APIキーが無いプロセスでLLMはheuristicに**静かにフォールバック**する。
これが過去のGLM安定性数値の一部を汚染していた(§6)。対策: .env自動読み込み、
`calls`/`fallbacks`計測、蒸留の実呼び出しゼロfail、実験後の呼び出し比率報告。
GLM安定性は実API検証済み(1seed×24ヶ月、所要2.5時間=384回の実呼び出し)で
再測定済み: 戦争20件・初回開戦t7・核保有国が当事者の戦争ゼロ。

## 6. 失敗の記録(再現性の担保)

開発中に発見・修正した主要な失敗。検証者はこれらが「後付けの言い訳」でない
ことをgit履歴で確認できる:

1. **輸出収益の複利爆発**: 輸出収入をGDPに絶対値加算したため資源輸出国が
   年20-70%成長し、6年で世界GDPが3倍になった。成長率ボーナス(上限+2.4%/年)に修正
2. **輸入インフレの二重計上**: 5商品の依存度×0.25の単純和がCPIの250%分に
   相当し、食料危機がインフレ死亡らせん(安定度−11/月)を生んだ。CPI上限25%で正規化
3. **LLMの無音フォールバック**: APIキー未ロードのプロセスでLLMがheuristicに
   静かに落ち、GLM実験の一部が偽装されていた。検出・撤回・再測定(§4.4)
4. **無音no-opパッチ**: 適用スクリプトのassert失敗で`--fine`フラグが訓練に
   届かず、fineモデルが粗行動で訓練されていた。npzの`fine`フラグ監査で発見。
   以後、パッチはassert必須+訓練冒頭に構成ログ
5. **GRUの分布シフト**: 学習速度を劇的に改善したGRUを176カ国に展開すると
   47カ国が崩壊。ドメインランダム化で解消(§4.2)
6. **予算慣性とRL学習の衝突**: ±10pt/期の慣性がRL学習を阻害(報酬差の消失)。
   ±15ptで学習(+3.1)と制約の両立を確認

## 7. 妥当性への脅威と読み方の規律

1. **絶対水準の非現実性**: chaosシナリオの戦争頻度(16カ国×6年で~150件)は
   現実の~50倍。同シナリオは意図的な極限ストレスであり、**相対比較に有効・
   絶対値に無効**。核なし299→現状155→拡散90という単調減少の**構造**が主張である
2. **同定されていない係数**: グレードCのパラメータ(抑止係数・思想・動員分布)は
   調整値である。これらが支配する結論(抑止の効果そのもの)は「この力学の下での」
   結果であって、現実の抑止についての証拠ではない
3. **振幅の下振れ**: 歴史検証で大規模ショックの価格振幅が一貫して下振れする
4. **単一シードのGLM結果**: 実APIの高コストのため1seed×24ヶ月。予備的観察として扱う
5. **簡易表現**: 16カ国earthプリセットはEUを単一主体とする等の粗さを持つ。
   176カ国earth_allが主結果の舞台である

**読み方**: 表の数値の差分(同seed・同シナリオ・層交換)が根拠。数値そのものを
現実の予測として扱わないこと。

## 9. 結果の要約と解釈

**Q1(AI意思決定者は安定性を変えるか)**: **文脈依存である**。拡散抑止の下では
学習AIが戦争を89.7→25.7件に減らし初回開戦をt15→t36へ遅らせる(構造を利用した
緩和)。一方、全カ国学習AI化は分布外の脆弱国家の安定を犠牲にする場合があり、
学習AI世界の100年は経済的に深く没落する(局所最適の寄せ集め)。思考AI(GLM)は
初回開戦を一貫して遅らせる(t7 vs t4)。→ AIの効果は「性質」単独でなく
「構造との相互作用」で決まる。

**Q2(抑止はAI相手でも機能するか)**: 機能する。核なし299→現状155→拡散90件と
単調減少し、**全構成・全AI層で核保有国が当事者の戦争はゼロ**(拡大抑止の核傘
を含む)。ただし抑止は「頻度」だけでなく「標的の選択」を変える — 核保有国は
攻撃対象から除外され、紛争は非保有国間に移動する。

**100年(2126年)**: 核拡散(9→35カ国)とイデオロギー二極化(全176カ国が非世俗化)の
下で大国間の持続戦争は消えるが、内部崩壊と債務・気候の複合ストレスで世界GDPは
−87%。学習AI世界も内政は良いがより深く没落する。→ **世紀スケールの構造的破綻は
個別政府の知性では停止できない。変えられるのは神(=制度設計)だけ**。
