# 3分デモ動画 台本（ storyboard ）

撮影環境:
- `cd server && uv run uvicorn terrarium.server.app:app --port 8788`（神の玉座）
- `python3 -m http.server 8787`（リプレイビューア）
- 画面収録: QuickTime（Cmd+Shift+5）1680×950 程度、日本語字幕なし喋り or テキストOverlay

| 時間 | 映像 | ナレーション（例） |
|---|---|---|
| 0:00–0:20 | スライド1（タイトル）→ スライド2 | 「Geopolitics Terrarium、神の地政学とバタフライエフェクト。プレイヤーは国家を治めず、神として世界に介入するだけ。国家AIたちが生存をかけた対応をし、その連鎖を観測します」 |
| 0:20–0:50 | `god.html`（8788）。地球プリセットで世界を作り、再生。航路アーク・海峡マーカーを映す | 「実世界の地図に、16の国家AIと実在の海峡、エネルギーから宇宙資源までのサプライチェーンが再現されています。1 tickが1時間の高速世界時計」 |
| 0:50–1:30 | ホルムズ海峡⚓をクリック→封鎖カード12時間→実行。イベントフィードに god_intervention、価格上昇を映す | 「ホルムズ海峡を封鎖します。エネルギー価格が急騰し——ここで注目は半導体。ファブが電力を必要とするため、エネルギー不足が半導体減産へ連鎖します。GDPは18.5%下落」 |
| 1:30–2:10 | 国家（日本）をクリック→ベイルアウト/利上げカードを見せる→「世界を創る」でリセットし、llm ポリシーを選んで再作成。rationaleが流れる様子 | 「介入カードは物理だけではありません。世界金利の引き上げ、債務国の救済、資源の創造、技術の禁止。さらに国家AIはLLM（z.ai GLM）が戦略を考え、強化学習が戦術を担う複合AIです。思考の理由がログに残ります」 |
| 2:10–2:40 | viewer（8788経由）。金融危機リプレイをscrub →「⏪ IF史」で t6・日本救済 を指定して分岐実行。分岐レポート（GDP+26.3・デフォルト-2・EU/米国の感染消失）を映し、IF世界のリプレイを開く | 「ここでIF史モード。日本が破綻したt7の直前、t6で救済していたら？——日本自体は救えませんでしたが、EUと米国への感染の連鎖が消えています。歴史の分岐点を書き換えて比較できる、これがこの作品の核心です」 |
| 2:40–3:00 | スライド9（感度行列）→ スライド10（まとめ） | 「どの介入点を変えれば連鎖が変わるか。全て同seedのA/BとIF反実仮想で定量比較でき、ログから誰でも再現できます。Geopolitics Terrarium、ご清聴ありがとうございました」 |

ポイント:
- 失敗テイクを恐れず「神の介入→即座にイベントフィードへ反映」の瞬間を必ず映す（ライブ感が審査基準の「挙動の確認」に直結）
- 封鎖直後の価格チャート/統計表の数字を読み上げる（再現性の実感）
- 最後にGitHubリポジトリURLを1枚挟む
