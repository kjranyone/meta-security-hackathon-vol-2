# 3分デモ動画 台本（ storyboard ）

撮影環境:
- `cd server && uv run uvicorn terrarium.server.app:app --port 8788`（介入モード・サーバ版）
- `python3 -m http.server 8787`（リポジトリルートで。SPAギャラリー+ブラウザ実行版）
- 画面収録: QuickTime（Cmd+Shift+5）1680×950 程度、日本語字幕なし喋り or テキストOverlay
- 推奨画面: `http://localhost:8788/#/god`（サーバ版）と `http://localhost:8787/web/`（ギャラリー）

| 時間 | 映像 | ナレーション（例） |
|---|---|---|
| 0:00–0:20 | スライド1（タイトル）→ スライド2 | 「Geopolitics Terrarium。プレイヤーは国家を治めず、介入者として世界に介入するだけ。国家AIたちが生存をかけた対応をし、その連鎖を観測します」 |
| 0:20–0:50 | `http://localhost:8788/#/god`。タイトル→状態モーダル→**「新しいシミュレーション」**で地球16カ国・学習AI 1本（約50MB）を配備して再生。海峡にホバー→「経由航路11本」のtooltip、国家にホバー→GDP・安定・戦争のtooltipを映す | 「実世界の地図に、16の国家AIと実在の海峡、エネルギーから宇宙資源までのサプライチェーンが再現されています。全国家の頭脳は教師LLMから蒸留した学習モデル1本。決定は週次、全動力学は実時間で校正されています」 |
| 0:50–1:35 | ホルムズ海峡をクリック→**封鎖**→実行（トースト「介入: 海峡 Strait of Hormuz を封鎖」）。**速度スライダーを上げて数日を早送り**。1-3日でエネルギー価格が急騰（価格急騰トースト・発光弧）、しかしGDPも戦争もまだ動かないことを統計表で示す。更に早送りして2-3週間で航路スロットルと価格2倍台へ | 「ホルムズ海峡を封鎖します。まず動くのは市場です——在庫が尽きるより先に、期待が価格へ載る。しかしGDPは動かない。輸送力の実効低下には2週間、備蓄揚耗には数ヶ月かかる。**介入は即時に効かない**——これが実時間校正です」 |
| 1:35–2:10 | 国家（日本）をクリック→介入HUD（救済/災害/資源の創造/技術の禁止/性格の書き換え）を開いて見せる。イベントフィードに「RL戦術AI: 予算 軍事20/福祉30…」の週次決定が流れる様子 | 「介入は物理だけではありません。世界金利、債務国の救済、資源の創造、技術の禁止。政府の判断は毎週ニューラルネットの推論で決まり、その内容がログに流れます」 |
| 2:10–2:35 | `http://localhost:8787/web/`（ギャラリー）→「ライブ介入モード」カード→**#/live**。起動オーバーレイ（数秒〜十数秒）→世界が動く。seed欄を42→7に変えて再創造し、違う世界が出るのを1−2秒映す | 「こちらはブラウザだけでも動く版。エンジンと学習モデル1本をWASMがそのまま実行します——移植ではなく同一コードで、ネイティブ実行と400tick・bit一致を検証済み。シードを変えれば、同じモデルから別の世界が生まれます」 |
| 2:35–2:50 | ギャラリーに戻り「ホルムズ海峡封鎖」カード→viewer。**t=0から再生**、海峡封鎖の瞬間に発光弧、タイムラインの事件マーカー（武力/経済危機/介入/制度）が**再生した過去分だけ**現れる様子をscrubで見せる | 「全記録は誰でもブラウザからscrubできます。未来は見せない——事件は通り過ぎた時に初めて見える。16カ国版では戦争1件、176カ国版では6件。同じ介入でも世界の規模で連鎖が変わります」 |
| 2:50–3:00 | スライド9（感度行列）→ スライド10（まとめ）→ リポジトリURL | 「全て同seedのA/BとIF反実仮想で定量比較でき、ログから誰でも再現できます。Geopolitics Terrarium、ご清聴ありがとうございました」 |

ポイント:
- 失敗テイクを恐れず「介入→イベントフィードへ即時反映」の瞬間を必ず映す（ライブ感が審査基準の「挙動の確認」に直結）
- **封鎖→翌日価格急騰→数週間で輸送力低下→数ヶ月で不足** の時間差を早送りで見せる（実時間校正が本作の差別化点）
- #/live の起動は2回目からキャッシュで速い。本番撮影前に一度開いておくと安全
- 速度表示の「×N (実効×M)」は計算が追いつかない時に実効が下がる誠実表示——必要なら言及
- 最後にGitHubリポジトリURLを1枚挟む
